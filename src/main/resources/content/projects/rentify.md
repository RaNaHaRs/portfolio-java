# Rentify

## Problem

An online rental marketplace for listing, searching, and renting properties.

## What I built

- Property listings and search
- Rental workflow
- Responsive user interface
- Cloud image storage

## Key decisions

- MVC architecture
- JPA and Hibernate integration
- Relational database design

## Result

Deployed on Render: [Rentify](https://rentify-render-g9w0.onrender.com/).

## Stack

Java, Spring Boot, Thymeleaf, MySQL, Bootstrap, JPA, and Hibernate.
