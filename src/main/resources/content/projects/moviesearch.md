# MovieSearch Recommendation Engine

## Problem

Combine machine-learning recommendations with a Java backend.

## What I built

- Movie recommendation engine
- Spring Boot backend
- Flask recommendation service
- API-based communication between services

## Key decisions

- Separate recommendation work into a Python Flask service
- Integrate the service with the Spring Boot backend over APIs

## Result

The source material lists a repository but no live demo.

## Stack

Spring Boot, Flask, Python, and JavaScript.
