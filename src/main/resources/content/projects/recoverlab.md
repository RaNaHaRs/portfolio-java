# RecoverLab CRM

> Internship contribution developed as part of the Selkey Cybersecurity team; not a solo project.

## Problem

Data-recovery business operations needed a multi-tenant customer relationship management platform.

## What I contributed

- Inventory and case management modules
- Dynamic field configuration
- User administration
- Responsive interface modules and REST API integration
- Debugging and cross-browser testing

## Key decisions and technical details

- Multi-tenant architecture and role-based access control
- PostgreSQL schema with more than 70 migrations
- REST APIs, JWT authentication, and Socket.IO
- Production deployment using aaPanel and Nginx

## Result

Production platform: [RecoverLab CRM](https://datarescuecrm.com/home).

## Stack

React.js, Node.js, Express.js, PostgreSQL, JWT, and Socket.IO.
